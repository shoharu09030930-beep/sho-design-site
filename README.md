# shoの業務自動化研究室 Webサイト

「面倒な手作業を、少しずつ自動化。」をテーマにした、shoの個人事業・自主制作ポートフォリオサイトです。

## 掲載内容

- Excel・CSVデータ整理
- 公開情報リサーチ・一覧化
- 売上集計・簡易自動化
- 業務改善の進め方
- note・X・YouTubeでの発信案内

## 制作方針

- PC、タブレット、スマートフォンに対応
- 架空データまたは確認可能な公開情報のみを掲載
- 実案件の機密情報やクライアント資料は掲載しない
- 自主制作物を実案件と誤認させない
- 結果だけでなく、確認方法と更新方法も示す

## 使用技術

- HTML / CSS
- TypeScript / React
- Next.js 16.2.12（App Router）

## ローカル確認

```bash
npm install
npm run dev
```

本番ビルドと自動確認は `npm test` で実行できます。

## 公開予定

GitHubでソースコードを公開し、Vercelの無料URLで一般公開する予定です。ローカルでのリンク・表示・掲載内容の確認は完了しており、外部公開のみ承認待ちです。
